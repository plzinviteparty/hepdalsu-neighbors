# 허달수의 다정한 이웃들

포트폴리오용 조사형 미스터리 방탈출 게임 리뉴얼 프로젝트.

## 현재 상태
- 기존 《후두부가 웃는군》 정적 게임 코드를 **별도의 저장소**로 복제했습니다.
- 게임 제목을 변경하고 저장 데이터 키를 `hepdalsu-neighbors-v1`로 분리했습니다.
- 조사, 퍼즐, 동료, 추격, 세이브 및 엔딩 시스템은 **현재 원본 구조를 유지**합니다.
- 시나리오와 디자인은 **아직 개편 전**입니다. 새 게임의 완성판이 아닙니다.

## 예정된 개편
- 1인칭 사고·조난 프롤로그
- 허달수와 교단의 흔적을 찾는 조사 및 방탈출 퍼즐
- 분기별 탈출 결말
- 외부 IP 기반 캐릭터 교체 및 독자적인 시각 디자인
- 중요 조사 장면의 삽화와 확대 기록 UI
- 대사·조사문 윤문, 모바일 점검 및 QA

## 참고
- 기존 게임: https://plzinviteparty.github.io/ghost-hunt-halloween-party/occiput-relay/
- 원형은 '대저택의 핼러윈 파티' 릴레이소설 프로젝트를 바탕으로 했습니다. 공동 창작자의 설정과 자료를 공개 포트폴리오에 재사용할 때는 권리·사용 허락을 점검해야 합니다.
- 원본 게임 저장소는 수정하지 않습니다.
- **임시 자산 의존성:** `raster.js`의 대형 제단 텍스처 1개는 현재 원본 GitHub Pages의 기존 파일을 불러옵니다. 시각 리뉴얼 시 신규 자산으로 교체할 예정입니다.
